# X-VIBE CYBER DEVELOPMENT
Professional & Personal Branding Portfolio Website

## 🚀 Overview
X-VIBE CYBER DEVELOPMENT is a high-performance, visually striking professional portfolio and personal branding website designed for developers, designers, photographers, content creators, and corporate professionals.

## 🛠️ Tech Stack & Features
- **Frontend**: HTML5, Tailwind CSS (via CDN with custom cyberpunk/modern styling)
- **Design Aesthetic**: Dark mode, neon accents, sleek glassmorphism, responsive grid layout
- **Interactive Gallery**: Filterable project showcase (Development, Design, Photography, Content)
- **Personal Branding**: Bio, skills breakdown, experience timeline, testimonials
- **Call to Action**: Direct contact form, social media links, and downloadable resume (CV)
- **Deployment Ready**: Configured for instant deployment on **Netlify**

## 📂 Project Structure
```text
├── index.html        # Main landing page & application code
├── netlify.toml      # Netlify deployment configuration
└── README.md         # Documentation
```

## 🌐 Deployment on Netlify
1. Push this repository to GitHub.
2. Log in to [Netlify](https://www.netlify.com/).
3. Click **Add new site** > **Import an existing project**.
4. Connect to your GitHub repository and deploy! (No build command needed).
